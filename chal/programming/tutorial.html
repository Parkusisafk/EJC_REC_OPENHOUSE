1. Getting Started

Welcome! This visual programming environment lets you build logic using blocks. Start by clicking the [ + ] button at the bottom to add your first block.

2. Key Blocks

  • Set variable: Store values in named variables (e.g., ans = 5).
  • If - Else: Run code conditionally based on comparisons.
  • Repeat: Loop a fixed number of times.
  • Output answer: Print results to the console.

3. IF-ELSE block

if(going to rain)

I bring umbrella

else

I dont bring umbrella

Thats clear? Well the IF-ELSE block offers 3 input fields:

  • Condition: if this is true, then the code below runs
  • True branch: Whats getting ran when condition is true
  • False branch: Whats getting ran when condition is false

4. Conditions

Remember algebra? Introducing variables, which are letters/words/symbols that correspond to a certain value , and can be used for various purposes. Such example include the input variables given. A value is given to "n".

  • == checks to see if both sides are equal. For example 5 == 5 returns true!
  • != checks to see if both sides are not equal. For example 3 != 2 returns true!
  • NONE (the one you saw above) simply means that you are only using one argument, you can leave the other (value) blank
  • apart from NONE, we have other arithmetic options:
  • '+', standing for addition between 2 numbers
  • '-', standing for subtraction
  • '*', standing for multiplication. Eg. 5*7 = 35
  • '/', standing for division and rounding down. Eg. 23 / 5 = 4
  • '%', standing for remainder after division. Eg. 23 % 5 = 3

9. Challenge

Time to get into what the challenge is about!

You are given input variable n, or k if there is 2 inputs

Your job is to read the challenge description and do the task accordingly, using the output block to output your final answer

As you can see there are 4 buttons

Run button: tests your code on the sample test cases given, you can view the output in console below

Submit button: submits your code for testing across all testcases

End Challenge button: If you give up then just press this, it will compute your score and quit

Clear button: Clears all blocks so you can restart
